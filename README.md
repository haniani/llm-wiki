# llm-wiki-template

Шаблон персональной LLM Wiki: LLM-агент компилирует твои источники в персистентную, компаундящуюся вики из связанных markdown-страниц. Человек курирует источники и задаёт вопросы; всю рутину (саммари, кросс-ссылки, index, log) делает агент.

## Быстрый старт

1. **Use this template** → создай новый репозиторий.
2. Склонируй его и открой в Claude Code (или в другом агенте, который читает `AGENTS.md`: Codex, Cursor и т.п.). Статьи по URL скачиваются целиком вместе с картинками через публичный Jina Reader (нужен только `curl`); если он недоступен — локально через trafilatura (нужен [uv](https://docs.astral.sh/uv/)). На Windows Claude Code запускает скрипты через Git Bash, так что всё работает и там. `CLAUDE.md` и `.agents/skills` — симлинки: на Windows перед клонированием включи Developer Mode и `git config --global core.symlinks true`, иначе git создаст вместо них текстовые файлы с путём.
   Опционально — локальный семантический поиск по вики через [qmd](https://github.com/tobi/qmd): находит страницы по смыслу, в любой словоформе и через языки. Нужен Node.js 22+ и разовая загрузка ~2.4 ГБ моделей; `setup` спросит, включать ли его.
3. Скажи: **«настрой вики»** — скилл `setup` спросит, для чего она (исследование, конспекты книг, подготовка к собесам, рабочие знания…), и подстроит категории, схему и доменные скиллы под ответ.

## Что внутри

- `AGENTS.md` — схема вики: роли, конвенции страниц, воркфлоу. Плейсхолдеры заполняются при setup. `CLAUDE.md` — симлинк на него для Claude Code.
- `raw/` — твои источники (immutable, агент их не изменяет и не переводит — хранятся на языке оригинала).
- `wiki/` — страницы вики на твоём языке (выбирается при setup); структуру категорий создаёт setup.
- `.claude/skills/` — скиллы агента в открытом формате Agent Skills (`.agents/skills` — симлинк на них для Codex; Cursor и VS Code читают `.claude/skills` сами):
  - `setup` — одноразовая настройка шаблона под домен (+ `enable-search.sh` включает поиск qmd);
  - `ingest` — интеграция источника (файл / URL / текст; `fetch-source.sh` скачивает статью целиком с картинками);
  - `lint` — health-check вики (+ `check-links.sh` для механических проверок);
  - `file` — сохранение ценного ответа из чата как страницы.

## Как пользоваться после настройки

- **Ingest**: положи источник в `raw/` (или дай URL) и скажи «заингести».
- **Query**: просто задавай вопросы — агент отвечает по вики и предлагает файлить ценное обратно.
- **Lint**: периодически проси «сделай lint вики».

Репозиторий удобно открывать как Obsidian vault (graph view покажет форму вики); в настройках Obsidian укажи attachment folder = `raw/assets`.
